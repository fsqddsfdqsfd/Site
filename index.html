Tutoriel GitanX UI Library

Bienvenue ! Ce guide explique comment installer et utiliser la librairie GitanX pour Roblox.

Installation

  1. Placez le script GitanX dans ReplicatedStorage.
  2. Ajoutez un LocalScript avec le code suivant :
local GitanX = require(game.ReplicatedStorage.GitanX)
local UI = GitanX:CreateWindow({ Name = "Interface GitanX" })

Exemple d’utilisation

local Tab = UI:CreateTab("Gameplay")
local Section = Tab:CreateSection("Actions")

Section:CreateButton("Boost vitesse", function()
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = 50
end)

Section:CreateToggle("Mode invincible", function(state)
    local hum = game.Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
    if hum then
        hum.MaxHealth = state and math.huge or 100
        hum.Health    = state and math.huge or 100
    end
end)

UI:Notify("Info", "Interface GitanX chargée avec succès !")

FAQ

Q : Peut-on changer le thème ?
R : Non, le thème est imposé pour garder un style cohérent.

Q : Où placer la librairie GitanX ?
R : Dans un ModuleScript, par exemple dans ReplicatedStorage.

Q : Est-ce que GitanX fonctionne dans Roblox Studio ?
R : Oui, vous pouvez tester directement vos interfaces dans Studio.
