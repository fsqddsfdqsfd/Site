Bienvenue sur le tutoriel GitanX

GitanX est une librairie UI moderne pour Roblox, inspirée de Rayfield, avec thèmes, onglets, contrôles et notifications.

Utilisez le menu ci-dessus pour explorer chaque fonctionnalité.

Installation

Chargez la librairie directement depuis GitHub avec loadstring :

loadstring(game:HttpGet("https://raw.githubusercontent.com/fsqddsfdqsfd/Site/refs/heads/main/test1.lua"))()

Ensuite, créez une fenêtre :

local GitanX = GitanX.new()
local UI = GitanX:CreateWindow({
    Name = "Interface GitanX",
    Theme = "Default"
})

Boutons

local Tab = UI:CreateTab("Gameplay")
local Section = Tab:CreateSection("Actions")

Section:CreateButton({Name="Boost vitesse", Callback=function()
    game.Players.LocalPlayer.Character.Humanoid.WalkSpeed = 50
end})

Toggles

Section:CreateToggle({Name="Mode invincible", Callback=function(state)
    local hum = game.Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
    if hum then
        hum.MaxHealth = state and math.huge or 100
        hum.Health    = state and math.huge or 100
    end
end})

Sliders

Section:CreateSlider({Name="Vitesse", Range={16,120}, Increment=1, Callback=function(val)
    local hum = game.Players.LocalPlayer.Character:FindFirstChildOfClass("Humanoid")
    if hum then hum.WalkSpeed = val end
end})

Dropdowns

Section:CreateDropdown({Name="Choix de map", Options={"Ville","Désert","Forêt"}, Callback=function(choice)
    print("Map choisie:", choice)
end})

Notifications

UI:Notify({Title="Info", Content="Interface GitanX chargée avec succès !", Type="Info", Duration=3})

Changer de thème

UI:ChangeTheme("Ocean") -- Thèmes disponibles: Default, Ocean, Amethyst, Light

FAQ

Q : Comment charger GitanX ?
R : Avec loadstring(game:HttpGet(...))().

Q : Quels contrôles sont disponibles ?
R : Boutons, Toggles, Sliders, Dropdowns, Keybinds, Notifications.

Q : Peut-on changer le thème ?
R : Oui, avec UI:ChangeTheme("Ocean") ou autres thèmes.
